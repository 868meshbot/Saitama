# Controls

## T-Deck Plus

The T-Deck can be used entirely by touch, entirely by keyboard and trackball, or by
any mix of the two.

| To do this | Touch | Keyboard / trackball |
|---|---|---|
| Move between items | | Roll the trackball |
| Select / open | Tap | Click the trackball, or Enter |
| Go back, close a popup | Tap the **X** (top right) or **Close** | Backspace |
| Scroll a list or chat | Swipe up or down | Roll the trackball |
| Change launcher page | Swipe left or right | Roll the trackball past the edge |
| Type | | Keyboard |
| Wake the screensaver | Tap | Any key, or the trackball |

If taps land in the wrong place, calibrate the screen: open the **Terminal** and type
`touch-cali`, then tap each crosshair in turn. `touch-cali reset` undoes it.

The keyboard backlight is set in **Settings > Keyboard Light** (a brightness level, Off,
or Auto, which lights it between set times and during Night Mode).

## Cardputer ADV

The Cardputer has no touchscreen: everything is done from the keyboard. The
highlighted item has an outline in the accent colour.

| To do this | Keys |
|---|---|
| Move up / down / left / right | `;` `.` `,` `/` (the keys with arrows printed on them) |
| Move between fields in a form | Tab |
| Select / open / tick a box | Enter, or the **G0** button |
| Go back, close a popup | Backspace, or Fn + `` ` `` (Esc) |
| Close a QR code | Any key |
| Move inside a text box | Hold **Fn** with the arrow keys |
| Wake the screensaver | Backspace or Esc |
| Wake a blank screen | Any key |

In a text box the arrow keys type their characters (`;` `.` `,` `/`). Press Tab or
Enter to leave the box, or hold Fn to use them as arrows.

Drop-down lists open as a full-screen column of buttons: move to the option you want
and press Enter, or press Backspace to leave it unchanged.
